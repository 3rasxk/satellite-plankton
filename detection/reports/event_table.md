Reading this honestly, by real cause:

- **th_003 (2009-03), th_008 (2010-07), th_012 (1981-02), th_014 (1983-05):** predate Sentinel-2's launch (2015-06-23). There is structurally no Sentinel-2 scene to find for these dates -- not a cloud rejection, not a search-window problem. th_012/th_014 also predate MODIS-Aqua's 2002 archive start for their own historical year, yet MODIS climatology is a day-of-year pool across *all* archive years, so it was still attempted and returned real numbers for th_014 (n=10, reliable) -- the seasonal baseline is checkable even when the specific historical year's own reading is not.
- **th_004 (2016-01, Cha-am Coast):** within the Sentinel-2 era, but zero scenes were returned by the Earth Engine collection query for the entire recorded month at this point -- an early-era tiling/coverage gap for this specific location, confirmed by a direct collection query, not a cloud rejection. MODIS climatology did return a value here (n=1, flagged unreliable by `climatology.py`'s own `MIN_RELIABLE_N=5` threshold).
- **th_006 (2019-08-27, Koh Loy):** Sentinel-2 scenes genuinely exist -- 20 candidate images were confirmed in the searched window by a direct collection query -- but every one was cloud-rejected (`cloud_fraction` over the `max_cloud_fraction=0.5` limit); this is real, heavy Aug-2019 monsoon-season cloud cover, not a missing-scene problem. MODIS climatology also returned no data at this coordinate.
- **th_010 (2020-02-11..20, Ang Sila): the one event that now produces a real reading.** Earlier versions of this report recorded it as failing the JRC Global Surface Water land/water mask at every radius from 30 to 250 m and called that "a real site characteristic", quoting the error text as the evidence. That was wrong: the error was a defect in this pipeline (JRC has no data over open ocean and the mask read that as land -- see LIMITATIONS.md 5), not a property of the site. With the mask fixed it returns Sentinel-2 bands at 30, 50 and 100 m, and MODIS climatology returns a real, reliable value (n=6). It is still not a calibration set: n=1, the species is karenia_sp rather than the Noctiluca the B2/B3 feature targets, and the reading exists only via the ETOPO1 fallback over a buffer whose brightness is consistent with a turbid pier strip. The coordinate was never adjusted to force a fit.

**One event supplies an index reading; none supplies a valid anomaly statistic.** Four coordinate-bearing events predate Sentinel-2, one has a scene-coverage gap, and one has complete cloud rejection in the reported search. The shared inability to score all 14 events is a separate design limitation: no valid spectral-index baseline exists.
